# 評価の材料と手順

この公開版の `eval/` には、**作った文だけ**(人の発言ではないもの)を入れています。実際の会話・録音・ログ・
評価の実行結果(`results_*`・`*.log`)、評価用の会話音声は含めません。公開コーパス(FLEURS、AMI)の音声・全文も
含めず、スクリプトが自分で取得・作り直します。

| 場所 | 中身 | 使うスクリプト |
|---|---|---|
| `terms/testset.json` | 用語・略語・人名の試験: 74 項目 × ja/en/zh/ko の並行文(1 項目で 12 方向 = 888 訳)。訳に出るべき用語つき | `scripts/eval_terms.py` |
| `terms/confusables.json` | 1 字違いの似た 2 文 44 組(前の文の訳を写さないかを見る) | `scripts/eval_terms.py cf` |
| `terms/it_testset.json` | IT 用語の試験文 220 項目 × 4 言語 | `scripts/eval_it.py` |
| `qual/dialogs/` | 作った対面の対話 9 本(ja↔zh・ja↔en・ja↔ko × 雑談・質疑・IT)。各発話に参照訳と「文脈が要るか」の印 | `scripts/eval_qual.py` |
| `fragments/fragments.json` | 日中の短文・断片・長文・時の語の 140 文(足し・抜けの検査用の `must` / `must_not` つき) | `scripts/eval_fragments.py` |
| `speed/sents.json` | 応答速度の評価用の作った対訳 18 文(短・中・長 各 6) | `scripts/eval_speed.py` |
| `long/mono.json` | 切れ目のない長い独白の評価用に作った文(zh / ja の対訳) | `scripts/eval_long.py` |
| `pace/` | 読み上げの速さの表(声ごとの 1 秒あたりの字数と誤り率)と上限 | `scripts/eval_pace.py` |

ほかのスクリプトが使う外部データ(取得は各自、ライセンスを確認してください):

- **FLEURS**(google/fleurs、CC BY 4.0): `scripts/eval_conv.py`(合成の2人会話)、`eval_pace.py`、`eval_terms.py fleurs`、`eval_models.py` が使います。`scripts/eval_conv.py` が並行文の TSV と音声から会話を作り直します。
- **AMI Meeting Corpus**(英語の実会議、CC BY 4.0): `scripts/eval_live.py`(実時間のベンチ)と `eval_notes.py`(会議メモ)が使います。
- `scripts/eval_meeting.py`: 台本のある合成会議を作って通します(台本はスクリプトの中。人名は例)。

## 回し方(例)

```sh
# 用語の評価(耳 = この Mac の SenseVoice、翻訳 = 設定した処理場所)
PYTHONPATH=src .venv/bin/python scripts/eval_terms.py --help
# 訳の質(COMET を足すには COMET の入った Python が別に要ります)
PYTHONPATH=src .venv/bin/python scripts/eval_models.py --help
# 応答速度(アプリそのものにマイクの代わりに作った音声を実時間で流します)
PYTHONPATH=src .venv/bin/python scripts/eval_speed.py --help
```

自分のアプリや Zoom が動いている間・ほかの評価が CPU を使っている間は、結果が揺れるので流さないでください
(スクリプトには、そのとき待つ・断る確認が入っているものがあります)。A/B で比べるときは、同じ時間帯に
交互に流します(回線と負荷の時間変化を打ち消すため)。

## 実測値のまとめ

開発中に主に M3・16 GB の Mac で測った値です。機材・負荷・ネットワークで動くので目安として見てください。
README の数字は、ここの表と同じです。

### 翻訳の質(用語テスト、FLEURS 30 文 × 12 方向)

| 翻訳エンジン | chrF(FLEURS 30 文 × 12 方向) | 用語が訳に出た割合(正解の原文 888 訳) |
|---|---|---|
| このMac(Gemma 3 4B、LM Studio) | 39.03 / 39.34(2 回) | 93.6% |
| リモートGPU(qwen3.8-flash-next) | 45.03 / 45.06(2 回) | 98.3% |

似た 2 文(2 文目が正しい割合 / 1 文目の訳が写った数): リモート 97.3% / 0、このMac 86.7% / 3(それぞれ 264 続け訳)。

### COMET(wmt22-comet-da、同梱の Gemma 3 4B QAT Q4_0、アプリと同じ依頼 + 長さの再試行)

材料: FLEURS 30 文 × 12 方向、IT 用語 40 項目 × 12 方向、作った対話 126 発話、日中の断片 140、計 1,106 訳。

| 版 | FLEURS | IT 用語 | 対話 | 断片 | 平均 |
|---|---|---|---|---|---|
| 長さの再試行・例を足す前 | 85.81 | 88.09 | 86.98 | 89.74 | 87.43 |
| 採用版(例 4 組を指示文の直後へ + 長さの再試行) | 86.04 | 88.13 | 88.54 | 90.72 | 87.83 |

同じ設定を 3 回流したときの揺れは chrF で FLEURS 40.9〜41.1・IT 54.4〜54.8・対話 42.3〜42.6・断片 39.1〜39.5 です。

### 応答の速さ(日→英・日→中、決まった速さ、作った対訳 18 文を実時間で)

話し終わりからの秒(中央 / p90)。11/08 時点のビルド。

| 処理場所 | 方向 | 訳の確定 | 声の鳴り始め | 飛ばした文 |
|---|---|---|---|---|
| このMac(LM Studio、Gemma 3 4B) | 日→英 | 0.85 / 1.69 | 1.56 / 2.55 | 0 |
| このMac | 日→中 | 0.82 / 1.9 | 1.14 / 2.07 | 0 |
| リモートGPU | 日→中 | 1.16 / 2.35 | 1.77 / 2.81 | 0 |
| リモートGPU(速い掛け合い: 話速 ×1.3、間 0.6〜0.9 秒) | 日→中 | 2.19 / 4.91 | 5.91 / 7.33 | 4 / 18 |
| リモートGPU(速い掛け合い) | 日→英 | 1.57 / 3.7 | 6.81 / 7.92 | 7 / 18 |

耳の速さ(開発機の M3): SenseVoice-Small は 1 区間あたり約 0.15 秒、Whisper large-v3-turbo は約 2.4 秒。
